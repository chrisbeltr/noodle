10print

10print is a one-liner program originally made in BASIC, a programming language for early computers. the original 10print is the pattern that you're seeing in the background, with the lines of forward and back slashes. you can see the variation i made for class by clicking the header for this section.

emoji painting

this programming assignment was inspired by emoji.ink (down at the time of writing), an experimental drawing app built by Yung Jake to make emoji portraits of celebrities. this variation uses randomized emojis and several different "tools" to allow users to create unique and somewhat chaotic emoji images. one of the prominent features is the slinging and wall bouncing logic, which is on display here. i wanted users to sling around the emojis but that would lead to a lot of them going off screen, so i decided to make the emojis bounce off the walls.

waterfall dictionary

i had an idea to make text that flows like a waterfall. the web had other things in mind. i could not find a good way to shift each line downwards from each other, so i had to manually measure each word to detect if it would wrap around in order to shift down the start of the next line.

the second part of this showcase is an ever growing dictionary definition. our assignment was to find an api to work with and the inspiration for the week was dadaist poems, so i wanted to make something with recurring defintions. the initial defintion is for a random word, with each word of that definition being clickable. once clicked, that word's definition replaces the word and all its words become clickable, and so on.

signs

on a long bus ride between cities in greece, i could do nothing but look out the windows at greek signs passing by. i found that i really liked the way they looked, as it was my first time in europe. i decided to try making a sort of "library" to make signs, with a class-based framework design similar to tailwind.

sol lewitt exercise

this was a little exercise we did on the first day of class. it's one of sol lewitt's pieces, which held these instructions:

  1. draw 24 tiny circles anywhere on the page
  2. connect 12 of the circles with straight lines
  3. connect 12 of the circles with wavy lines

while this is a trivial task, we found that all of the resulting drawings were very unique. somehow, this task was very non trivial in code, due to the logic of drawing a squiggly line requiring a whole bunch of math and trigonometry. however, i was still able to somewhat replicate the feeling of the hand drawn versions thanks to the randomness of the circle placement.
